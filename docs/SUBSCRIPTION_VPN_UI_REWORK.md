# 订阅、VPN 控制与首页 UI 重构

分支：`fix/subscriptions-vpn-integration`（基于 `0dcb894`，未强推、未覆盖他人提交）。

## 已修复

1. 首页顶部重复的 VPN 启动按钮已删除；启动控制收敛到底栏常驻控件。
2. 订阅卡片内嵌节点：展开即显示该订阅的节点，节点不再单独平铺成“节点卡片”。
3. 订阅卡片右侧新增 on/off 开关，用于启用/禁用订阅。
4. 展开后的节点右侧新增 on/off 开关，用于启用/禁用节点，并保留编辑/删除。
5. 订阅展开区新增“测速本订阅节点”，测速只对该订阅节点执行，禁用节点不参与。
6. 保存订阅后会把刷新结果反馈到首页提示（成功导入数量或失败原因），不再静默失败。
7. VPN 状态不再用遥测连接冒充：
   - `SbAiVpnService` 运行在 `:core` 进程，其 `status` 是进程内 StateFlow，UI 进程读不到真实值。
   - 新增 `VpnRuntimeState`：服务把 Starting/Running/Stopping/Stopped/Error 写入 SharedPreferences，UI 进程读取。
   - 底栏按钮与首页状态均基于该真实阶段；启动/停止进行中忽略重复点击。
   - 首页左上角会显示“启动失败 · 具体错误”，便于判断 sing-box 核心是否真的启动失败。
8. 恢复底栏实时磨砂，但只让底栏自身做低半径采样；全页 `layerBackdrop` 保持关闭，以保留已修复的首页流畅性。

## 订阅解析与误过滤

- 修正信息节点过滤：强关键词需量词/链接佐证，弱关键词（“流量”“到期”）需量化数据，
  避免真实节点被误判为信息节点；已让既有测试与新增回归测试同时通过。
- 回归测试覆盖 URL-safe base64、缺 padding/BOM、Clash/singbox 识别、协议按 type 匹配等。
